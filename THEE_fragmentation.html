Basic model of evolutionary rescue in discrete time

Jan Leuenberger & Safeeya Ramis

2026-10-27

1. Introduction

This report documents a stochastic simulation of evolutionary rescue in discrete time, based on the model of Orr & Unckless introduced in the practical. We extended the basic model with habitat fragmentation: at a chosen generation (split_time) the population is split into two separate habitats (B and C) of different size, each with its own carrying capacity.

Biological scenario

  • A haploid population consists of wild-type individuals (a) and, possibly, mutant individuals (A).
  • A sudden environmental change makes the wild type unfit: it declines at rate decay_rate.
  • The mutant is beneficial (advantage sel_coeff) and can grow in the new environment, but it is initially rare or absent. If absent, it has to arise by mutation from the wild type.
  • The population is rescued if the mutant spreads before the wild type (and with it the whole population) goes extinct. -The Habitat gets seperatated at a defined time called split_time.Individuals are randomly distributed, each habitat has a smaller carrying capacity, and both then evolve independently.

Research Questions

  • Is evolutionary rescue possible in the Fragmented habitats?
    • What is the impact of split_time on ER?
    • What is the impact of the habitat porportions on ER?

1.1 Overview of the code

  1. simulate_one_gen(): simulates one generation (reproduction with logistic growth + mutation) for one habitat.
  2. simulate_pop(): runs a full simulation: one habitat until split_time, then two habitats (B and C) afterwards.
  3. Plot functions (plot_split(), plot_habitat(), plot_habitats()): visualise a single simulation run.
  4. run_scenarios() and to_long(): repeat the simulation many times for different parameter values and summaries the rescue probability.
  5. Three analyses: split time varies, habitat proportion varies, and both.

1.2 Parameters and variables

Name Meaning
N_a, N_A current size of the wild-type / mutant population (change over time)
N_init_a, N_init_A initial sizes of wild type (positive integer) and mutant (non-negative integer)
decay_rate detrimental effect of the environment on the wild type (> 0 so that extinction is possible)
sel_coeff selective advantage of the mutant (should be > decay_rate to allow rescue)
mut_rate mutation rate from wild type to mutant (> 0 and small)
t_max maximum number of generations simulated (a setting, not a model parameter)
split_time generation at which the fragmentation happens (integer > 0)
split_ratio probability with which each individual is assigned to habitat B at the split (between 0 and 1)
habitat_prop share of the total carrying capacity given to habitat B (between 0 and 1); habitat C gets 1 - habitat_prop
K carrying capacity of the original (unsplit) habitat; limits growth and is divided among B and C in the same proportions as the habitats

Simulating evolutionary rescue in discrete time

In this notebook, we are implementing simulations of evolutionary rescue by a single mutation in discrete time, as discussed and analyzed in the work by Orr & Unckless. The model is as follows: a haploid population starts with a given number of wild-type and mutant individuals. Because of a sudden environmental change, the wild type is unfit and declines in the new environment. The mutant is beneficial and can survive and expand in the new environment, but it starts at a low (or zero) frequency in the total population. In order to rescue the population, it has to outcompete the wild type. If the mutant is not present at time 0, it has to appear through mutation and then spread in the population before extinction occurs.

Simulate one generation of population size change

We want to observe the numbers of wild-type and mutant individuals over time. As first step, we simulate one generation of the population. At time \(t\), the population has \(N_a\) wild-type individuals and \(N_A\) mutant individuals. First, these reproduce. This is modeled by drawing a Poisson random variable according to the expected absolute number \(N_a \cdot (1-r)\) of wild-type individuals, where \(r\) is the decay rate of the wild type, and \(N_A \cdot (1-r+s)\) of mutant individuals, where \(s\) is the selective advantage of the mutant over the wild time. Then mutation from \(a\) to \(A\) occurs as a Poisson random variable according to the given mutation rate. This defines the composition of the population at time \(t+1\).

set.seed(57)

simulate_one_gen <- function(N_a, N_A, decay_rate, sel_coeff, mut_rate, K) {
  # total population size and per-capita growth rates without competition
  N_tot <- N_a + N_A
  rho_a <- -decay_rate
  rho_A <- sel_coeff - decay_rate
  # logistic growth: crowding reduces the growth of both types equally (set to 0 if negative)
  mean_a <- N_a * max(0, 1 + rho_a - rho_A * N_tot / K)
  mean_A <- N_A * max(0, 1 + rho_A - rho_A * N_tot / K)
  # draw offspring according to Poisson distribution
  offsp_a <- rpois(1, mean_a)
  offsp_A <- rpois(1, mean_A)
  
  # draw new mutants according to Poisson distribution
  mut_a_to_A <- rpois(1, offsp_a * mut_rate)
  
  # determine new population sizes of wild type and mutant
  N_a_new <- offsp_a - mut_a_to_A
  N_A_new <-  offsp_A + mut_a_to_A
  
  return(c(N_a_new, N_A_new))
}

Less common functions used

  • set.seed(57): initialises R’s random number generator. With the same seed, all “random” draws are repeated identically, so results can be reproduced. Without it every knit gives different numbers.
  • rpois(n, lambda): draws n random numbers from a Poisson distribution with mean lambda. The Poisson distribution describes counts of independent events, which is a natural model for the number of offspring.
  • max(0, x): returns the larger of the two values, used here as a floor at 0.
simulate_pop <- function(N_init_a, N_init_A, decay_rate, sel_coeff, mut_rate, t_max, K, habitat_prop, split_ratio, split_time) {
  # Create the vector in which to save the results
  pop_vector <- c(N_init_a, N_init_A)
  # initiate the variables
  pop_new <- c(N_init_a, N_init_A)
  
  # Create the vectors for the new habitats
  pop_vector_B <- NULL
  pop_vector_C <- NULL
  
  # run the simulation until generation t_max
  for (i in 1:t_max) {
    
     # Time when the fragmentation occur
    if (i == split_time + 1) {
      
    # Create the new habitats (creating new K)
    K_B <- K * habitat_prop
    K_C <- K * (1 - habitat_prop)
    
    #create the ratio of the splitting
    split_ratio_B <- split_ratio
    split_ratio_C <- (1 - split_ratio_B)
    # print(split_ratio_B)
    # print(split_ratio_C)
    # Distribute individuals  randomly to the habitat B
    n_B_a <- rbinom(1, pop_new[1], split_ratio_B) 
    n_B_A <- rbinom(1, pop_new[2], split_ratio_B)   

    # Distribute individuals randomly to the habitat C
    n_C_a <- pop_new[1] - n_B_a
    n_C_A <- pop_new[2] - n_B_A

    # Calculate the new populatins for B an C 
    pop_new_B <- simulate_one_gen(n_B_a, n_B_A, decay_rate, sel_coeff, mut_rate, K_B)
    pop_new_C <- simulate_one_gen(n_C_a, n_C_A, decay_rate, sel_coeff, mut_rate, K_C)
    
    # add the new population sizes to the output vector
    pop_vector_B <- rbind(pop_vector_B,pop_new_B)
    pop_vector_C <- rbind(pop_vector_C,pop_new_C)
    
    }
    
    if (i > split_time + 1) {

    pop_new_B <- simulate_one_gen(
      pop_new_B[1], pop_new_B[2],
      decay_rate, sel_coeff, mut_rate,K_B
    )

    pop_new_C <- simulate_one_gen(
      pop_new_C[1], pop_new_C[2],
      decay_rate, sel_coeff, mut_rate,K_C
    )

    # Save the results for each generation
    pop_vector_B <- rbind(pop_vector_B, pop_new_B)
    pop_vector_C <- rbind(pop_vector_C, pop_new_C)

    # define the row and column names of the output vector
    rownames(pop_vector_B) <- (0:t_max)[1:length(pop_vector_B[,1])] 
    rownames(pop_vector_C) <- (0:t_max)[1:length(pop_vector_C[,1])]
    colnames(pop_vector_B) <- c("a","A")
    colnames(pop_vector_C) <- c("a","A")
    
    }
    
    # Continue simulating habitat A only until split_time
if (i <= split_time) {
  
    # redefine the current population one generation later
    pop_new <- simulate_one_gen(pop_new[1],pop_new[2], decay_rate, sel_coeff, mut_rate,K)
    # add the new population sizes to the output vector
    pop_vector <- rbind(pop_vector,pop_new)
    # condition to stop the simulation before t_max: either the population exceeds 1.5 times the original population size, or it goes extinct
    if (pop_new[1]+pop_new[2]>=2*(N_init_a+ N_init_A) | pop_new[1]+pop_new[2]==0) break
}
    
 }
  # define the row and column names of the output vector
  rownames(pop_vector) <- (0:t_max)[1:length(pop_vector[,1])] # note that the vector has to be cut if the simulation stopped early
  colnames(pop_vector) <- c("a","A")
  
  # Data frames
    pop_vector_df <- as.data.frame(pop_vector)
    pop_vector_B_df <- as.data.frame(pop_vector_B)
    pop_vector_C_df <- as.data.frame(pop_vector_C)
  # return all three population vectors separately
  return(list(main = pop_vector_df, B = pop_vector_B_df, C = pop_vector_C_df))

  
}

Less common functions used

  • rbinom(n, size, prob): draws n random numbers from a binomial distribution, i.e. the number of “successes” among size independent trials, each with success probability prob. Here: how many of the individuals are assigned to habitat B.
  • rbind(x, y): “row-bind”, appends y as a new row below x. Starting from NULL, the first rbind creates the matrix. This is how the time series grows by one row per generation.
  • rownames() / colnames(): set the labels of the rows / columns of a matrix. (0:t_max)[1:length(...)] creates the generation numbers and cuts them to the actual number of rows.
  • break: leaves the for loop immediately (used for early stopping).
  • |: element-wise logical “or” (here equivalent to || since both sides are single values).
  • as.data.frame(): converts a matrix into a data frame, so columns can be accessed with $ (e.g. output$B$A). as.data.frame(NULL) gives an empty data frame with 0 rows, which is how we detect runs that ended before the split.
  • list(main = ..., B = ..., C = ...): returns several objects of different size in one named container.

# ---- 1. Overview plot: wild type and mutant before the split,
#         total of habitats B and C after the split, legend outside ----
plot_split <- function(output, K, habitat_prop, split_time, xlim_max = NULL) {

  main <- output$main
  B    <- output$B
  C    <- output$C

  K_B <- K * habitat_prop
  K_C <- K * (1 - habitat_prop)

  # population sizes before the split (wild type and mutant separately)
  wt_main  <- main$a
  mut_main <- main$A

  # total population sizes after the split
  tot_B <- B$a + B$A
  tot_C <- C$a + C$A

  # generation numbers
  gen_main <- 0:(length(wt_main) - 1)
  gen_B    <- split_time + seq_along(tot_B)
  gen_C    <- split_time + seq_along(tot_C)

  # axis ranges
  x_max <- if (is.null(xlim_max)) max(c(gen_main, gen_B)) else xlim_max
  y_max <- max(c(K, wt_main, mut_main, tot_B, tot_C), na.rm = TRUE)

  # make room on the right for the legend, restore settings afterwards
  old_par <- par(mar = c(5, 4, 4, 11))
  on.exit(par(old_par))

  plot(NA, xlim = c(0, x_max), ylim = c(0, y_max * 1.05),
       xlab = "Generation", ylab = "Population size",
       main = "Evolutionary rescue with habitat fragmentation")

  # carrying capacities: K only until the split, then K_B and K_C
  segments(0, K, split_time, K, col = "black", lty = 2, lwd = 2)
  segments(split_time, K_B, x_max, K_B, col = "darkgreen",  lty = 2, lwd = 2)
  segments(split_time, K_C, x_max, K_C, col = "darkorange", lty = 2, lwd = 2)

  # before the split: wild type and mutant
  lines(gen_main, wt_main,  col = "blue",      lwd = 2)
  lines(gen_main, mut_main, col = "firebrick", lwd = 2)

  # after the split: total of habitat B and C
  if (length(tot_B) > 0) lines(gen_B, tot_B, col = "darkgreen",  lwd = 2)
  if (length(tot_C) > 0) lines(gen_C, tot_C, col = "darkorange", lwd = 2)

  # split time
  abline(v = split_time, col = "grey40", lty = 3, lwd = 2)

  # legend outside, at the top right corner of the plot region
  legend(x = par("usr")[2], y = par("usr")[4], xpd = TRUE, bty = "n",
         xjust = 0, yjust = 1, cex = 0.85,
         legend = c("Wild type (before split)", "Mutant (before split)",
                    "Habitat B (total)", "Habitat C (total)",
                    "K (before split)", "K_B", "K_C", "Split time"),
         col = c("blue", "firebrick", "darkgreen", "darkorange",
                 "black", "darkgreen", "darkorange", "grey40"),
         lty = c(1, 1, 1, 1, 2, 2, 2, 3), lwd = 2)
}

# ---- 2. Single habitat panel (used for B and C) ----
plot_habitat <- function(df, K_hab, split_time, title, col_tot, xlim_max = NULL) {

  if (is.null(df) || nrow(df) == 0) {
    plot.new()
    title(main = paste(title, "- no data (population ended before the split)"))
    return(invisible(NULL))
  }

  gens  <- split_time + seq_len(nrow(df))
  tot   <- df$a + df$A
  x_max <- if (is.null(xlim_max)) max(gens) else xlim_max
  y_max <- max(c(K_hab, tot), na.rm = TRUE)

  plot(NA, xlim = c(split_time, x_max), ylim = c(0, y_max * 1.05),
       xlab = "Generation", ylab = "Population size", main = title)

  abline(h = K_hab, col = col_tot, lty = 2, lwd = 2)       # K of this habitat
  abline(v = split_time, col = "grey40", lty = 3, lwd = 2) # split time

  lines(gens, tot,  col = col_tot,     lwd = 2)  # total
  lines(gens, df$a, col = "blue",      lwd = 2)  # wild type
  lines(gens, df$A, col = "firebrick", lwd = 2)  # mutant
  
  

  legend(x = par("usr")[2], y = par("usr")[4], xpd = TRUE, bty = "n",
         xjust = 0, yjust = 1, cex = 0.85,
         legend = c("Total", "Wild type (a)", "Mutant (A)", "K", "Split time"),
         col = c(col_tot, "blue", "firebrick", col_tot, "grey40"),
         lty = c(1, 1, 1, 2, 3), lwd = 2)
  
  ##adding the starting population
    legend(x = par("usr")[2], y = par("usr")[4], xpd = TRUE, bty = "n",
         xjust = 0, yjust = 1, cex = 0.85,
         legend = c("Total",
                    paste0("Wild type (a), start ", df$a[1]),
                    paste0("Mutant (A), start ", df$A[1]),
                    "K", "Split time"),
         col = c(col_tot, "blue", "firebrick", col_tot, "grey40"),
         lty = c(1, 1, 1, 2, 3), lwd = 2)
}

# ---- 3. Two panels: habitat B on top, habitat C below ----
plot_habitats <- function(output, K, habitat_prop, split_time, xlim_max = NULL) {

  K_B <- K * habitat_prop
  K_C <- K * (1 - habitat_prop)

  # two panels stacked, with room on the right for the legends
  old_par <- par(mfrow = c(2, 1), mar = c(4, 4, 3, 11))
  on.exit(par(old_par))

  plot_habitat(output$B, K_B, split_time, "Habitat B", "darkgreen",  xlim_max)
  plot_habitat(output$C, K_C, split_time, "Habitat C", "darkorange", xlim_max)
}

Less common functions used

  • par(): sets global graphics parameters. mar = margins (bottom, left, top, right) in lines; mfrow = c(2, 1) = a grid of 2 rows × 1 column of plots. par() returns the old values, which we save in old_par.
  • on.exit(par(old_par)): registers code that runs automatically when the function ends, restoring the original graphics settings so that later plots are not affected.
  • plot(NA, ...): draws an empty coordinate system (nothing is plotted for NA); lines and segments are then added manually.
  • segments(x0, y0, x1, y1): draws a straight line between two points; used for the carrying-capacity lines that only span part of the x-axis.
  • abline(v = ..., h = ...): draws an infinite vertical (v) or horizontal (h) line.
  • lines(x, y): adds a line connecting the points to an existing plot.
  • legend(): adds a legend. par("usr") returns the plot region’s coordinates (x-min, x-max, y-min, y-max), so par("usr")[2] and [4] are the top-right corner. xpd = TRUE allows drawing outside the plot region, bty = "n" removes the legend box, xjust/yjust set which corner of the legend is anchored at that point.
  • seq_along(x) / seq_len(n): safe ways to create 1, 2, ..., length(x) or 1, ..., n (they return an empty sequence for empty input, unlike 1:length(x)).
  • if (...) a else b used as an expression: x_max <- if (is.null(xlim_max)) ... else ... assigns one of two values.
  • plot.new() + title(): create a blank plot and add a title, used as a placeholder when there is no data.
  • invisible(NULL): returns NULL without printing it.
  • paste0(): joins strings without separator, used to put the starting numbers in the legend.

Therefore, to get interpretable results, we have to run the simulation many times and summarize the outcome depending on the question of our study. # ---- fixed parameters --------------------------------------------------
init_a           <- 600
init_A           <- 0
m_rate           <- 0.001
max_gen_analysis <- 1000
K_analysis       <- 1000
no_replicates    <- 10     # more replicates give more precise probabilities
max_attempts     <- 5000
rescue_frac      <- 1       # rescue = A >= rescue_frac * K of the habitat

# ---- core function: your loop, wrapped so it can be reused -------------
run_scenarios <- function(split_times, habitat_props) {
  results <- list()
  
  for (st in split_times) {
    for (hp in habitat_props) {
      
      K_B <- K_analysis * hp
      K_C <- K_analysis * (1 - hp)
      
      i <- 0
      attempts <- 0
      repeat {
        attempts <- attempts + 1
        if (attempts > max_attempts) {
          warning(paste("Too many failed runs for st =", st, "hp =", hp))
          break
        }
        
        one_run <- simulate_pop(
          init_a, init_A,
          decay_rate   = 0.01,
          sel_coeff    = 0.2,
          mut_rate     = m_rate,
          t_max        = max_gen_analysis,
          K            = K_analysis,
          habitat_prop = hp,
          split_ratio  = 0.5,
          split_time   = st
        )
        
        # skip runs that ended before the split time
        if (nrow(one_run$B) == 0 || nrow(one_run$C) == 0) next
        i <- i + 1
        
        reached_B <- one_run$B$A >= rescue_frac * K_B
        reached_C <- one_run$C$A >= rescue_frac * K_C
        rescued_B <- any(reached_B)
        rescued_C <- any(reached_C)
        
        results[[length(results) + 1]] <- data.frame(
          st = st,
          hp = hp,
          replicate = i,
          rescued_B = rescued_B,
          rescued_C = rescued_C,
          rescued_any  = rescued_B | rescued_C,
          rescued_both = rescued_B & rescued_C,
          gen_B = if (rescued_B) which(reached_B)[1] else NA_integer_,
          gen_C = if (rescued_C) which(reached_C)[1] else NA_integer_
        )
        
        if (i >= no_replicates) break
      }
    }
  }
  
  data_table <- do.call(rbind, results)
  
  # rescue probability per scenario, with binomial standard error
  rescue_prob <- data_table %>%
    group_by(st, hp) %>%
    summarise(
      n = n(),
      across(c(rescued_B, rescued_C, rescued_any, rescued_both), mean),
      .groups = "drop"
    )
  
  list(data = data_table, prob = rescue_prob)
}

# ---- helper: long format with SE for plotting --------------------------
to_long <- function(rescue_prob) {
  rescue_prob %>%
    pivot_longer(
      cols = c(rescued_B, rescued_C, rescued_both),
      names_to = "population",
      values_to = "rescue_probability"
    ) %>%
    mutate(
      se = sqrt(rescue_probability * (1 - rescue_probability) / n),
      population = recode(
        population,
        rescued_B    = "Population B",
        rescued_C    = "Population C",
        rescued_both = "Both populations"
      )
    )
}
